# Task Manager Web App

A PHP and MySQL based Task Management System designed to help users organize, manage, and track their daily tasks.

## Project Overview

This project is being developed as a web-based task management application using PHP, MySQL, HTML, CSS, and JavaScript.

## Planned Features

- User Registration and Login
- Email OTP Verification
- User Profile Management
- Change Password
- Add, Edit, and Delete Tasks
- Task Categories
- Task Priority Management
- Pending and Completed Tasks
- Overdue Task Tracking
- Dashboard with Task Statistics
- Email Task Reminders

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap (if used)
- XAMPP
- PHPMailer

## Development Environment

This project is being developed locally using XAMPP.
